# WoW Forever Suite

An independent collection of addons for **World of Warcraft: Forever**.

## Our projects

| Addon | Purpose |
|---|---|
| WoW Forever Core | Shared technical runtime |
| Roster | Character roster and longitudinal progression |
| Chronicle | Character history and gameplay memory |
| Relics | Persistent memories associated with individual items |
| Campfire Log | Memories of camps and social encounters |
| WoW Tabletop Engine | Social tabletop games inside WoW |

## Development

The suite is developed as a collection of modular addons with independent responsibilities, versioning, and releases.

Source code, documentation, issue tracking, and releases are maintained through this GitHub organization.
